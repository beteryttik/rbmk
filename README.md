# RBMK — мод-конструктор АЭС для Minecraft 1.21.1 (NeoForge)

## Сборка
- Требуется JDK 21
- Локально: `gradle build` (или `gradle wrapper`, затем `./gradlew build`)
- На GitHub: Actions соберёт jar автоматически при push

## Статус: каркас волны 2
- Регистрация ~98 декоративных и конструкционных блоков
- Креативная вкладка RBMK
- Текстуры — автосгенерированные плейсхолдеры (заменяются в Blockbench)
- Логика реактора (тепло, реактивность, АЗ-5, взрыв) — следующий этап
